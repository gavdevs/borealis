# Borealis icon studies

**Selected: B / North (2026-09-25).** The user chose the open ring with the
north-east arrow. It replaces the phone outline in the companion wordmark and
is also the companion favicon. The other marks remain exploratory alternatives.

- **Curtain:** three upright flowing strokes, referencing an aurora.
- **North:** open ring and north-east pointer; more literal/navigation-oriented.
- **Open B:** a minimal, open letterform.

Each source is a 24-unit, currentColor SVG. `comparison.svg` shows enlarged and
20 px wordmark applications in both polarities. No external fonts or images
are required by the marks. The sheet uses an installed system font.
